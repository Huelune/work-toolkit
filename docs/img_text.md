# img_text — 이미지 글자를 텍스트로

[← README](../README.md)

이미지 안의 글자를 읽어 텍스트 파일로 저장합니다.
Windows에 들어 있는 글자 인식(OCR)을 쓰므로 **설치할 것이 없고, 이미지가 PC 밖으로 나가지 않습니다.**

```bash
python tools/img_text.py "D:\캡처\화면.png"   # → D:\캡처\화면.txt
python tools/img_text.py "D:\캡처"            # 폴더 안의 이미지 모두
```

- 이미지와 같은 폴더에 같은 이름의 `.txt`가 생깁니다. 이미 있으면 덮어씁니다.
- 지원 형식: png, jpg, bmp, gif, tif. 폴더를 주면 그 폴더만 봅니다 (하위 폴더 제외).
- 화면에는 변환한 개수와 실패 이유별 개수만 나옵니다.

## 알아두면 좋은 점

- Windows 10 이상에서만 됩니다. Python 안에서 Windows 기능을 직접 부르므로 PowerShell 같은 다른 프로그램을 띄우지 않습니다 (실행이 정책으로 막힌 PC에서도 동작).
- 한국어 인식은 `Motor_Init` 같은 코드 식별자의 `_`와 그 옆 글자를 틀리게 읽을 때가 있습니다. 코드 화면은 결과를 꼭 대조하세요.
- 인식 언어는 Windows 표시 언어를 따릅니다. 한국어 Windows면 한글과 영문·숫자를 함께 읽습니다.
- 화면 캡처처럼 글자가 작은 이미지는 글자 크기를 보고 자동으로 확대해서 읽습니다. 그래도 틀리면 화면을 확대(Ctrl+휠)한 뒤 캡처하면 나아집니다.
- 줄은 글자의 위치를 기준으로 위에서 아래, 왼쪽에서 오른쪽 순서로 맞춥니다. 들여쓰기는 남지 않고, `{`처럼 글자 하나뿐인 줄은 빠질 수 있습니다.
- 표는 줄 단위 글자로만 나옵니다 (칸 구분 없음). `0`/`O`, `1`/`l`/`I`, `U`, `_` 같은 글자는 꼭 확인하세요. 16진수(`0x1F`)와 접미사(`1U`)가 특히 잘 틀립니다.

## 종료 코드

| 코드 | 뜻 |
|---|---|
| 0 | 모두 변환 |
| 1 | 일부 실패 또는 이미지 없음 |
| 2 | 글자 인식을 실행하지 못함 |

## 문제 해결

| 증상 | 해결 |
|---|---|
| `글자 인식 언어가 없음` | Windows 설정 > 시간 및 언어 > 언어에서 한국어(또는 영어) 언어 팩 설치 |
| `이미지를 열 수 없음` | 이미지 형식이 맞는지, 문서보안(DRM)이 걸려 있지 않은지 확인 |
| `이미지가 너무 큼` | 이미지를 줄이거나 잘라서 다시 실행 |
