# img_text — 이미지 글자를 텍스트로

[← README](../README.md)

이미지 안의 글자를 읽어 텍스트 파일로 저장합니다.
Windows에 들어 있는 글자 인식(OCR)을 쓰므로 **설치할 것이 없고, 이미지가 PC 밖으로 나가지 않습니다.**

```bash
python tools/img_text.py "D:\캡처\화면.png"   # → D:\캡처\화면.txt
python tools/img_text.py "D:\캡처"            # 폴더 안의 이미지 모두
```

- 이미지와 같은 폴더에 같은 이름의 `.txt`가 생깁니다. 이미 있으면 덮어씁니다.
- 지원 형식: png, jpg, bmp, gif, tif. 폴더를 주면 그 폴더만 봅니다 (하위 폴더 제외).
- 화면에는 변환한 개수와 실패 이유별 개수만 나옵니다.

## 알아두면 좋은 점

- Windows 10 이상에서만 됩니다.
- 인식 언어는 Windows 표시 언어를 따릅니다. 한국어 Windows면 한글과 영문·숫자를 함께 읽습니다.
- 글자가 작으면 잘 틀립니다. 캡처를 크게 하거나 이미지를 확대해 다시 돌리면 나아집니다.
- 표는 줄 단위 글자로만 나옵니다 (칸 구분 없음). `0`/`O`, `1`/`l` 같은 글자는 꼭 확인하세요.

## 종료 코드

| 코드 | 뜻 |
|---|---|
| 0 | 모두 변환 |
| 1 | 일부 실패 또는 이미지 없음 |
| 2 | 글자 인식을 실행하지 못함 |

## 문제 해결

| 증상 | 해결 |
|---|---|
| `글자 인식 언어가 없음` | Windows 설정 > 시간 및 언어 > 언어에서 한국어(또는 영어) 언어 팩 설치 |
| `이미지를 열 수 없음` | 이미지 형식이 맞는지, 문서보안(DRM)이 걸려 있지 않은지 확인 |
| `이미지가 너무 큼` | 이미지를 줄이거나 잘라서 다시 실행 |
