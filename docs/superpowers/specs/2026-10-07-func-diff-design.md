# func_diff — C 함수 단위 비교 도구 설계

작성일: 2026-10-07

## 목적

두 폴더의 `.c` 파일을 **함수 단위**로 비교해 함수 단위 코드 리뷰를 돕는다.
대상 코드는 Simulink 자동 생성 코드와 직접 작성한 임베디드 C가 섞여 있다.
기존 `folder_diff.py`는 그대로 두고 별도 도구 `func_diff.py`로 만든다.

## 사용법

```bash
python func_diff.py 폴더A 폴더B -l 목록.xlsx -o report   # 주 용도: 목록의 함수만 비교
python func_diff.py 폴더A 폴더B -o report                # 목록 없이 모든 함수 + (함수 외) 비교
```

옵션은 `folder_diff`와 같게 맞춘다: `-w`, `-B`, `-x`, `-c`, `-o`, `--html`, `--excel`, `--summary`, `--no-color`.
`-e`의 기본값은 `.c`이다 (`-e .c .h`처럼 넓힐 수 있음).
종료 코드: 0 = 차이 없음, 1 = 차이 있음, 2 = 읽기 오류 또는 분석 불가 파일 있음.

## 비교 대상 목록 (`-l`)

- 엑셀(`.xlsx`): 첫 시트의 A열은 파일명, B열은 함수명. 텍스트 파일은 한 줄에 `파일명,함수명` 형식이고, 탭 구분도 허용한다.
- 파일명 칸이 비어 있거나 병합 셀이면 위쪽 파일명을 이어서 쓴다.
- 첫 줄이 제목(파일명·함수명·file·function 등)이면 건너뛴다.
- 파일명은 `folder_diff -l`과 같은 규칙으로 찾는다: 파일명만 쓰면 하위 폴더 어디서든 찾고, 대소문자는 무시하고, 상대 경로와 glob 패턴도 가능하다.
- 함수명 칸이 비어 있으면 그 파일의 모든 함수를 비교한다.
- 함수명에 `(함수 외)`를 쓰면 그 파일의 함수 외 영역을 비교한다. 목록이 있을 때 함수 외 영역은 이렇게 명시한 경우에만 포함한다.
- 함수명은 대소문자를 구분한다. C는 대소문자를 구분하기 때문이다.

## 함수 찾기 (표준 라이브러리 스캐너)

1. 원본에서 주석, 문자열/문자 리터럴, 전처리 줄(`\`로 이어지는 줄 포함)을 공백으로 가린다. 줄 번호와 글자 위치는 유지한다.
2. 가린 텍스트에서 중괄호 깊이를 추적한다. 깊이 0에서 `{`를 만나면 직전 `;`·`}`·파일 시작 이후 텍스트를 선언부 후보로 본다.
3. 선언부가 `)`로 끝나고(공백 무시) 깊이 0에 `=`가 없으면 함수로 판정한다. 함수 이름은 마지막 `( … )` 바로 앞의 식별자다.
4. 함수 범위는 선언부 첫 줄부터 닫는 `}` 줄까지다. 함수 위 설명 주석은 함수 외 영역에 속한다.
5. 같은 이름의 함수가 한 파일에 여러 번 나오면 `foo`, `foo#2`처럼 구분한다.
6. 함수에 속하지 않는 줄은 모아서 `(함수 외)` 항목 하나로 만든다. 원래 줄 번호는 유지한다.
7. 파일 끝에서 깊이가 0이 아니거나 중간에 음수가 되면 그 파일은 **분석 불가**로 처리한다. 경고를 띄우고 파일 전체 diff로 대체한다.

## 비교와 상태

- 같은 상대 경로의 파일끼리 짝짓고, 그 안에서 같은 이름의 함수끼리 비교한다.
- 줄 비교는 `folder_diff`와 같다: `-w`/`-B`를 적용하고, 원본 줄 번호와 원문을 표시한다.

| 상태 | 뜻 |
|---|---|
| 변경 | 양쪽에 있고 내용이 다름 |
| 동일 | 양쪽에 있고 내용이 같음. 위치만 바뀐 경우도 포함 |
| A에만 | A 파일에만 있음 (삭제) |
| B에만 | B 파일에만 있음 (추가) |
| 함수 없음 | 목록에 있지만 A·B 양쪽 파일 모두에 없음 |
| 파일 없음 | 목록에 있지만 파일이 A·B 양쪽 폴더 모두에 없음 |
| 분석 불가 | 중괄호 짝 불일치. 파일 전체 diff로 대체 |

파일이 한쪽 폴더에만 있으면 그 파일의 함수는 모두 A에만 또는 B에만으로 표시한다.

## 결과물

- **콘솔**: 상태별 개수 요약을 보여주고, 파일별로 함수 목록과 상태를 보여준다. `--summary`가 아니면 변경 함수의 unified diff도 출력한다(원본 줄 번호 기준).
- **엑셀** (`-o NAME` → `NAME.xlsx`)
  - `요약` 시트: 폴더, 생성 시각, 옵션, 상태별 개수
  - `함수 목록` 시트: 파일 | 함수 | 상태 | A 줄 범위 | B 줄 범위 | 추가 | 삭제 | 비고 | **검토 결과** | **검토 의견**
    - 검토 결과·검토 의견은 리뷰어가 채우는 빈 열이다.
    - 상태별 색상, 필터, 첫 행 고정을 적용한다.
    - 변경·A에만·B에만·분석 불가 항목의 함수명은 HTML의 해당 위치로 링크한다.
- **HTML** (`NAME.html`)
  - 파일별 구역 안에 함수마다 접이식 항목을 둔다.
  - 변경 함수는 나란히 비교(글자 단위 강조)로 보여준다.
  - A에만·B에만 함수는 본문 전체를 한쪽에 보여준다.
  - 동일 함수는 접힌 목록으로 보여준다.
  - `#앵커`로 열면 해당 항목을 자동으로 펼친다.

## 코드 구조

- `func_diff.py` (새 파일): 목록 읽기, C 스캐너, 함수 짝짓기와 비교, 콘솔·HTML·엑셀 출력.
- `folder_diff.py`에서 재사용하는 것:
  - 파일 수집(`collect_files`, `match_targets`)
  - 읽기(`decode_lines`, `normalize`)
  - diff 표시(`unified_lines`, `diff_rows`, `html_table`, CSS)
  - 엑셀 셀 작성 도우미
- 재사용을 위해 `folder_diff.py`에서는 동작을 바꾸지 않는 범위의 작은 정리만 한다. 예: `write_excel` 안의 셀 작성 도우미를 모듈 수준으로 꺼낸다.
- `func_diff.py`는 `folder_diff.py`와 같은 폴더에 있어야 한다.

## 오류 처리

- 파일 읽기 실패는 `folder_diff`와 같이 오류 목록으로 보고하고, 종료 코드는 2다.
- 분석 불가 파일은 경고와 함께 파일 전체 diff로 대체하고, 종료 코드는 2다.
- 목록 파일이 없거나 `.xls`이거나 비어 있으면 안내 메시지를 내고 종료한다.
