# work-toolkit

업무에 쓰는 파이썬 도구 모음입니다.
**이전 버전과 현재 버전을 비교해서 무엇이 추가·삭제·변경되었는지** 파악하는 데 씁니다.

| 도구 | 하는 일 |
|---|---|
| `tools/folder_diff.py` | 이전·현재 버전 폴더에서 **추가·삭제·변경된 파일**과 바뀐 줄을 찾음 |
| `tools/func_diff.py` | 이전·현재 버전의 `.c` 파일에서 **추가·삭제·변경된 함수**를 찾음 (함수 단위 코드 리뷰용) |

두 도구 모두 `이전폴더 현재폴더` 순서로 지정합니다.

---

## 1. 준비

1. **Python 3.8 이상**이 필요합니다. 명령 프롬프트(또는 PowerShell)에서 확인합니다.
   ```bash
   python --version
   ```
2. **엑셀 리포트를 쓰려면** openpyxl을 한 번 설치합니다. 엑셀 기능을 쓰지 않으면 설치하지 않아도 됩니다.
   ```bash
   pip install -r requirements.txt
   ```
3. 아래 명령은 모두 **이 폴더(work-toolkit)에서** 실행합니다.
   ```bash
   cd D:\codes\useful_tool
   ```

> 경로에 공백이 있으면 따옴표로 감쌉니다: `"D:\내 작업\v1.0"`

### 폴더 구성

```
work-toolkit/
├─ tools/             도구 (folder_diff.py, func_diff.py)
├─ reports/           리포트 저장 위치 (git에 올라가지 않음)
├─ tests/             자동 테스트
├─ docs/              설계 문서
├─ requirements.txt   엑셀 기능용 패키지 목록
└─ README.md
```

## 2. folder_diff — 버전 간 파일 변경 파악

이전 버전 폴더와 현재 버전 폴더의 파일을 **같은 상대 경로끼리** 짝지어, 어떤 파일이 추가·삭제·변경되었는지 보여줍니다.

### 가장 많이 쓰는 방법

```bash
python tools/folder_diff.py "D:\release\v1.0" "D:\release\v1.1" -o reports/v1.1_비교
#                            └ 이전 버전        └ 현재 버전
```

- 화면에 추가·삭제·변경 개수와 바뀐 줄이 출력됩니다.
- `reports/v1.1_비교.xlsx`(파일 목록)와 `reports/v1.1_비교.html`(변경 내용)이 만들어집니다.

### 결과 보는 법

| 파일 | 내용 |
|---|---|
| **엑셀** `.xlsx` | `요약` 시트: 추가·삭제·변경·동일 개수 / `파일 목록` 시트: 파일마다 상태와 추가 줄·삭제 줄 수. 필터로 "추가"만, "삭제"만 골라 보기 가능. **변경된 파일 경로를 클릭하면 HTML의 해당 diff로 이동** |
| **HTML** `.html` | 변경된 파일별로 이전(왼쪽)·현재(오른쪽)를 나란히 비교. 바뀐 글자는 진하게 강조. 파일 이름을 클릭하면 펼쳐짐 |

| 상태 | 뜻 |
|---|---|
| 추가 | 현재 버전에 새로 생긴 파일 |
| 삭제 | 현재 버전에서 없어진 파일 |
| 변경 | 두 버전에 모두 있고 내용이 다름 |
| 동일 | 두 버전이 완전히 같음 |
| 형식만 다름 | 내용은 같고 줄바꿈(CRLF/LF)·인코딩·BOM·파일 끝 줄바꿈만 다름 |
| 무시됨 | `-w`/`-B` 옵션으로 무시한 공백 차이만 있음 |
| 찾을 수 없음 | `-l` 목록에 적었지만 두 버전 어디에도 없음 |
| 오류 | 권한 없음 등으로 읽지 못함 |

### 자주 쓰는 옵션

| 옵션 | 설명 | 예 |
|---|---|---|
| `-o 이름` | 엑셀+HTML 리포트 저장 | `-o reports/결과` |
| `-w` | 줄 앞뒤 공백, 줄바꿈 형식 차이 무시 | |
| `-B` | 빈 줄 차이 무시 | |
| `-e 확장자…` | 지정한 확장자만 비교 | `-e .c .h` |
| `-x 패턴…` | 제외할 파일·폴더. `/`가 있으면 경로로 비교 | `-x build "src/*.tmp"` |
| `-l 목록파일` | 목록에 적은 파일만 비교 (아래 참고) | `-l 대상.xlsx` |
| `--summary` | 화면에는 파일 목록만 (diff 생략) | |
| `-c 숫자` | diff 앞뒤로 보여줄 줄 수 (기본 3) | `-c 10` |
| `--excel 파일` / `--html 파일` | 리포트 하나만 저장 | |

`.git`, `.svn`, `__pycache__`, `*.pyc`, `*.asv`, `slprj` 등은 기본으로 제외됩니다.

### 비교 대상 목록 (`-l`)

목록에 적은 파일만 비교합니다. 엑셀은 **첫 시트의 A열**, 텍스트 파일은 **한 줄에 하나**(`#`으로 시작하면 주석)입니다.

| A열 |
|---|
| 파일명 ← 첫 칸이 제목이면 자동으로 건너뜀 |
| main.c |
| src/util/*.c |
| config.ini |

- 파일명만 쓰면 하위 폴더 어디에 있든 찾습니다 (대소문자 무시, 같은 이름이 여러 곳이면 모두 비교).
- `src/main.c` 같은 경로, `*.c` 같은 패턴도 쓸 수 있습니다.
- 두 버전 어디에도 없는 항목은 "찾을 수 없음"으로 표시됩니다 (오타 확인용).

## 3. func_diff — 버전 간 함수 변경 파악

이전 버전과 현재 버전에서 같은 경로의 `.c` 파일끼리 짝지은 뒤, **파일 안의 함수를 이름으로 짝지어**
어떤 함수가 추가·삭제·변경되었는지 보여줍니다. 함수 순서가 바뀌거나 위치가 옮겨져도 같은 함수끼리 비교합니다.

### 가장 많이 쓰는 방법: 목록에 있는 함수만 리뷰

1. 엑셀로 리뷰할 함수 목록을 만듭니다 (**첫 시트, A열 = 파일명, B열 = 함수명**).

   | 파일명 | 함수명 |
   |---|---|
   | motor.c | Motor_Init |
   | | Motor_Step |
   | sensor.c | Sensor_Read |
   | sensor.c | (함수 외) |
   | util.c | |

2. 실행합니다.
   ```bash
   python tools/func_diff.py "D:\src\v1.0" "D:\src\v1.1" -l 리뷰목록.xlsx -o reports/함수리뷰
   #                          └ 이전 버전    └ 현재 버전
   ```
3. `reports/함수리뷰.xlsx`를 열어 리뷰합니다. 함수명을 클릭하면 HTML에서 해당 함수의 diff가 열립니다.
   **검토 결과 / 검토 의견** 열이 비어 있으니 그대로 리뷰 체크리스트로 쓰면 됩니다.

### 목록 작성 규칙

| 이렇게 적으면 | 이렇게 동작 |
|---|---|
| 파일명 칸이 비어 있음 (또는 병합 셀) | 바로 위 파일명을 이어서 사용 |
| 함수명 칸이 비어 있음 | 그 파일의 **모든 함수** (함수 밖 코드는 제외) |
| 함수명에 `(함수 외)` | 함수 밖 코드(전역 변수, `#define`, `#include` 등)를 비교 |
| 같은 이름 함수가 여러 개 (`#if`/`#else`) | 결과에 `f`, `f#2`로 표시. 목록에 `f`라고 쓰면 모두, `f#2`라고 쓰면 그것만 |
| 첫 줄이 "파일명 / 함수명" 같은 제목 | 자동으로 건너뜀 |

- **파일명**은 대소문자를 구분하지 않고 하위 폴더 어디서든 찾습니다. **함수명**은 대소문자를 구분합니다.
- 텍스트 목록도 됩니다: 한 줄에 `파일명,함수명` (탭으로 구분해도 됨).

### 목록 없이 전체 비교

```bash
python tools/func_diff.py "D:\src\v1.0" "D:\src\v1.1" -o reports/전체함수
```

모든 `.c` 파일의 모든 함수와 `(함수 외)`를 비교합니다.

### 함수별 상태

| 상태 | 뜻 |
|---|---|
| 추가 | 현재 버전에 새로 생긴 함수 |
| 삭제 | 현재 버전에서 없어진 함수 |
| 변경 | 두 버전에 모두 있고 내용이 다름 |
| 동일 | 두 버전에 모두 있고 내용이 같음 (위치만 바뀐 경우 포함) |
| 함수를 찾을 수 없음 | 목록에 적었지만 두 버전 파일 모두에 없음 → 함수명 오타·대소문자 확인 |
| 파일을 찾을 수 없음 | 목록에 적었지만 파일이 두 버전 폴더 모두에 없음 |
| 분석 불가 | 중괄호 짝이 맞지 않아 함수를 나눌 수 없음 → 파일 전체 diff로 대신 보여줌 |

이름이 바뀐 함수는 "삭제(옛 이름) + 추가(새 이름)"로 표시됩니다.
엑셀 `함수 목록` 시트의 **이전 줄 / 현재 줄** 열은 각 버전 파일에서 그 함수가 있는 줄 범위입니다.

### 옵션

folder_diff와 같습니다 (`-o -w -B -x -c -l --summary --excel --html`). `-e`의 기본값은 `.c`이며, 헤더도 보려면 `-e .c .h`.

### 알아두면 좋은 점

- Simulink 자동 생성 코드, `FUNC(void, CODE) Foo(void)`(AUTOSAR), `__interrupt`, 함수 뒤 `__attribute__((…))`, OSEK `TASK(이름)`/`ISR(이름)`을 인식합니다.
- 함수로 인식하지 못하는 형태: K&R 스타일 정의, Keil `interrupt N`/`reentrant`, 함수 포인터를 반환하는 정의, `extern "C" { }` 안의 함수. 이런 함수는 `(함수 외)`에 포함되거나 목록에서 "함수를 찾을 수 없음"으로 나옵니다.
- 같은 파일을 목록에 "함수명 빈칸" 행과 `(함수 외)` 행으로 **둘 다** 적으면 `(함수 외)`가 빠집니다. 이럴 땐 함수명을 직접 나열하세요.

## 4. 공통 사항

### 종료 코드 (배치·CI에서 활용)

| 코드 | folder_diff | func_diff |
|---|---|---|
| 0 | 차이 없음 | 차이 없음 |
| 1 | 차이 있음 | 차이 있음 |
| 2 | 읽기 오류 | 읽기 오류 또는 분석 불가 파일 있음 |

### 문제 해결

| 증상 | 해결 |
|---|---|
| `엑셀 파일을 다루려면 openpyxl이 필요합니다` | `pip install -r requirements.txt` |
| `구버전 엑셀(.xls)은 읽을 수 없습니다` | 엑셀에서 `.xlsx`로 다른 이름으로 저장 |
| 리포트 저장 시 `Permission denied` | 같은 이름의 엑셀 파일이 열려 있음 → 닫거나 `-o`에 다른 이름 사용 |
| 한글이 깨져 보임 | 파일은 UTF-8·CP949·UTF-16을 자동 인식합니다. 콘솔이 깨지면 `-o`로 리포트를 만들어 확인 |
| 엑셀 링크를 눌렀는데 HTML 맨 위가 열림 | 일부 Office 환경의 제한입니다. HTML에서 해당 파일·함수를 클릭해 펼치세요 |

### 개발자용

```bash
python -m unittest discover -s tests -v
```

- 엑셀 기능 외에는 표준 라이브러리만 사용합니다.
- `func_diff.py`는 `folder_diff.py`의 기능을 가져다 쓰므로 두 파일은 같은 폴더(`tools/`)에 있어야 합니다.
- 설계 문서: `docs/superpowers/specs/`, 구현 계획: `docs/superpowers/plans/`
